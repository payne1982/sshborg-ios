<en-US>
• More room in the terminal: the title bar hides itself and comes back when you tap the screen, so the text takes the whole height (it can be kept fixed in Settings).
• A short login message is readable straight away: the session's first lines now start below the retracting title bar.
• SFTP: move files and folders on the server — cut them in one folder and paste them in another. The server does the move itself, so even a very large file moves instantly and nothing is downloaded.
• SFTP: while selecting files, tapping a row now ticks it instead of starting a download.
• SFTP: tapping a file now opens its menu — download, open in the editor, cut, rename — instead of starting a download straight away. The download icon beside it is a button on every row.
• The message a server shows before login now appears above the password request, so you can read it before typing.
