<en-US>
• Mosh (experimental): a terminal that survives a change of network and the phone being put away. The screen lives on the server, so the same shell with the same programs still running in it is there when you come back. Turn it on per host — the server needs mosh-server installed and its UDP ports reachable.
• Mosh through a bastion: a host whose first hop has Mosh on is reached the other way round — Mosh to that machine, then one ssh line from there — so the terminal sits where the network does not change.
• The file editor now saves without ever leaving a half-written file: if a save is interrupted, what was on the server is still what was on the server.
• SFTP: file names sent by a server are checked before they are used, so a server cannot point the app outside the folder you are looking at.
• Jump hosts: choosing them now starts from your own host list, with the typed form a tap away.
</en-US>

• ファイルエディタは、書きかけのファイルを残さずに保存します。保存が中断されても、サーバー上には元のままのものが残ります。
• SFTP: サーバーが送ってくるファイル名は使う前に検査されるので、いま見ているフォルダの外へアプリを向けさせることはできません。
• 経由ホスト: 選択は自分のホスト一覧から始まり、手で入力する形式もワンタップで使えます。
